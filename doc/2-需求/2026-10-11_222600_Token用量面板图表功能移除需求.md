# Token 用量面板图表功能移除需求

- 编号：REQ-TOKEN-USAGE-CHART-REMOVAL-20261011
- 提出时间：2026-10-11（用户）
- 收口时间：2026-10-11 22:26（北京时间）
- 状态：已实现并通过门禁，随 `workbuddy-token-usage 0.2.6` 发布

## 1. 用户诉求（原文口径）

> Token 用量统计的这些图标的功能全部移除, 相关的统计逻辑也可以不要了, 这样可以节省很多计算资源, 响应数据也少一些。

经 AskUserQuestion 拍板的两项边界：

1. 移除范围：**只移除 4 个图表** —— Token 用量趋势柱状图、模型使用占比环形图、成本趋势折线图、模型效率散点图，以及导出菜单里的"导出图表图片"按钮。
2. 后端处理：**同步移除图表专用接口与聚合**，不是只在前端隐藏。

保留项（用户未要求移除，且服务卡片与两张表）：顶部 4 张统计卡片、请求明细表、维度汇总表、价格本管理、备份/恢复、重置、CSV 导出、来源/服务商/API Key 筛选。

## 2. 边界澄清（实现前已核对代码事实）

- `/costs` 接口的 `series` 字段只被成本趋势图消费 → 去掉 `series`，接口与 `summary`/`models`/`missing_prices` 保留。
- `/stats/initial` 只有 `series` 与 `bucket_seconds` 是趋势图专用；`summary`/`models`/`sources`/`last_used`/`api_keys` 供卡片与筛选器 → 接口保留，去掉两个图表字段。
- `/stats/trends` 是图表唯一入口，前端已无其它调用 → 接口与其查询模式、聚合函数一并下线。
- `/stats` 接口前端本就无调用（历史死接口），不在图表依赖链上 → 按最小改动不动它。
- 图表下钻状态 `selectedModel` / `hiddenModels` 的唯一写入者是环形图扇区、图例和散点点击（`selectModel` / `toggleModel`）；图表移除后这两个状态永远为空，因此连同其查询参数拼装（`model=`、`exclude_model=`）、CSV 行过滤、`render()` 状态回收、`resetModelButton` 一并移除，避免留下"永远为假的分支"。
- 聚合粒度下拉 `#granularity` 的唯一消费者是趋势图分桶（`bucketInfo` / `nextBucketInfo`），故一并移除；它原本还是来源筛选下拉的 DOM 插入锚点，改为挂在隐藏的 `#range` 之后，位置不变。

## 6. 风险与回滚

- 主要风险是"误删卡片/表格仍在使用的共享函数或状态"，已用逐符号外部引用审计 + 两个真实执行 DOM 桩脚本 + 后端契约测试三重兜底。
- 回滚方式：回退 `token-usage-tracker` 目录到 0.2.5 并重新 `plugin-store install?version=0.2.5`（图表代码在 Git 历史中完整保留）。
